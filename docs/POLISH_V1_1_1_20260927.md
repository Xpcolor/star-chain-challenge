# 星链对战 V1.1.1 本地试玩

本轮仅本地修改，分支 `fix/cockpit-feedback-v1-1-1`。试玩地址 http://127.0.0.1:8792/ 。等待用户确认后才允许创建 PR、推送 GitHub 和发布。线上仍是已发布的 V1.1.0；不复用上一轮发布授权。

## 已完成

- 顶部改为“星链对战 V1.1.1”，说明书标题同版本。版本来自统一构建元数据；正式发布构建检查版本高于 `deployment-status.json` 的上一版。规则或说明书摘要改变时，必须重新核对 `docs/manual-review.json`，否则构建拒绝。摘要只能检测文档变动，不能替代人工核对规则含义。
- 目标提示点从 4px 增至 12px。合法运算的预计落点显示 20px 三角星，略小于 24px 当前定位菱形；不为三角星专门避让闪电，刻度文字仍在下方。
- 按最后确认的路线：每侧只有原有两条长闪电，沿一个连续外框和内部“弓”字路线追逐。中间经过小框上下边缘与空隙，不逐个绕小框一圈、不增加独立闪电。3 项与 4 项布局自动更新路线；阴影描边按八段亮度合并绘制。
- 原创 64 秒轻音乐循环，与音效开关共用。首次交互解锁；切后台暂停，返回继续；重开不叠加或打断音乐。音效继续按事件播放。生成脚本及原始 WAV 已纳入资产库。
- 新等级首次陨落时，碎片材质曾集中编译。原因是舰队在动画帧之间加载，TSL 的 FRAME 场景通道复用了旧画面，使原预热调用没有真正渲染新碎片。现在预热与清屏阶段临时按 RENDER 执行，再恢复 FRAME；入场前已完成准备。
- 新边缘加入后复查长文案，修复较矮桌面和手机小框溢出。低高度桌面将伤害数字与目标标题同行；手机保留字号，增加纵向空间。第 8 级手机星云选择器与四项面板也保持分离。

## 验证

87 项单元测试、类型检查、构建及 11 项浏览器场景全部通过。浏览器覆盖完整人机对局、补牌/重开、16 艘敌舰、WebGL/缺模型降级、进场与陨落至少两秒展示、四连击后陨落、音乐单声轨开关与重开。

UI 检查覆盖 2179×1244、1774×887、1280×720、390×844 的三项与四项布局；使用真实合法运算产生落点，并加入长说明/维修明细显示样本。无横向溢出，三角星不碰刻度文字。窄屏采用纵向滚动；静态截图不能替代实际观看追逐动效。

同机 Chrome/WebGPU 首次致命四连击短测：修复前，第 8/16 级分别出现 54/61ms 主线程长任务，且陨落时才创建 6 个碎片节点构建器；修复后这两个等级的首次陨落新增构建器为 0，最终第 1/8/16 级样本均无 50ms 以上主线程长任务。最终帧间隔最大仍偶有 50.1ms，不能据此保证所有设备恒定流畅。

核验回执：`docs/qa/polish-v1.1.1-verification.json`。本地原始日志、逐帧记录及截图在 `.local/qa/polish-*`、`.local/qa/fatal-*`。测试数据隔离在 `.local/polish-qa`，试玩保留 `.local/star-chain.sqlite`。未改游戏数值，本轮无需重跑公平性模拟。混音与最终审美仍等待用户实际试听、试玩。

## 后续版本维护

每次正式更新先递增 `package.json`/锁文件版本，同步 Worker 与经典入口版本，核对实际玩法并更新说明书回执；运行 `npm run verify`。以 `DEPLOY_ENV=production` 构建时会额外拒绝重复或回退的版本号。发布后才更新线上版本回执；不要提前把本地候选写成已发布。
