# V1.1.5 加速回原位规则

用户授权：加速允许返回原位，按最终局面判定攻击，不限定次数。

- A + 两张不同实体数字牌可回到出发点；每次出牌只按最终局面结算一次，各次出牌没有额外的使用次数限制，照常消耗牌。
- 玩家和机器人共用判定。中间不能小于 0、最终必须在 0–20，其余规则不变。
- 蓝4、紫10、橙16，紫10 + 8 − 8 = 10，等距三星基础伤害为3。中途经过18不触发18精准目标。
- 规则版本升级为 flight-records-4；旧版1–3按原规则回放，V3支援历史和用户既有记录继续保留。游戏、说明书同步为V1.1.5。
- 实测额外发现加速的越界提示遮住第二步减号；改为正常流布局，加速操作区预留自身高度。

验证：92项自动测试通过，含80局完整模拟（5–12轮，平均10.85轮）与36组镜像对局；双方各5次重复回原位通过；类型、构建、最终7项定向复核通过。一个真实浏览器流程覆盖4种视口，选择A和两张8、改加减、三角落点、确认、牌消耗、实际伤害均通过，页面无异常。实测含紫潮+1、护盾抵消2，因此等距基础3对应实扣2，进退自如回复1，HP从24/24到25/22。

浏览器第一次验证被提示框挡住按钮，修复后重新执行通过。自动模拟仅用于回归与双方规则对称核验，不代表真实玩家胜率。
