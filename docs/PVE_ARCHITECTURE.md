# 人机驾驶舱架构 · 2026-09-27

本次范围：完整人机版；可替换的联网接口；真人房间以后实施。用户最终限定：玩家固定一艘、不需要更换；近看、真实转向和独立侧光只提供给自己的飞船。既有玩法、难度、旧记录与认证边界保留。

## 运行链

React 操作 → `MatchClient.dispatch(Command)` → 本地控制器/纯规则 → 带 revision 的 ViewSnapshot → React、ScenePort、AudioBus。

- `src/contracts.ts`：协议版本、matchId、指令 ID、回执、订阅、结算事件契约。
- `LocalMatchClient`：同指令 ID 去重，拒绝旧对局与未知协议，隔离控制器异常，向 UI 发布复制快照。
- `dist/engine.mjs`、`records.mjs`：经过模拟和重放验证的纯规则与记录逻辑，继续使用 JavaScript。新增应用、界面和表现层使用严格 TypeScript；不是把所有历史 JS 文件改名为 TS。
- React 负责卡牌、数轴、目标、补给、菜单与数值轮盘，保留 DOM 节点和焦点。已有选择/说明/记录模板经 `Markup` 转为 React 节点，属于兼容边界；正式界面不再整页 innerHTML 重建。`classic.html` 保留旧界面对照。
- Zustand 只管理减弱动效、我方近看、我方侧光偏好，不裁定游戏结果。

未来实现 RemoteMatchClient 时仍需服务器验证指令、房间身份、权威结算、超时、断线快照恢复、存档一致性和速率限制。本次没有把本地 receipt 去重当作服务端防作弊，也没有上线伪房间。Cloudflare Durable Objects 可在下一阶段评估。

## 画面与声音

- 一个主 Three.js 渲染器统一背景平面、空间陨石、舰船、护盾、炮火和后处理。WebGPU 优先，Three.js 自动回落 WebGL 2；GPU/模型不可用时切为舰图，规则和按钮继续可用。
- NodeMaterial / TSL / RenderPipeline：选择性辉光、短促 RGB 位移和覆盖整个三维战场的冲击波。屏幕文字仍用 DOM，以保持清晰和可访问性。
- 三维动作和 HUD 电弧由一个场景时钟推进；GSAP 时间轴按该时钟取样。受击仅短暂停住舰船姿态，界面与粒子继续运行。重开清除旧时间轴、弹道和重复事件标记。
- 三个大区域各两条长电弧；小区域用悬浮文字。侧面玻璃约 17% 底色，底部约 20%，两侧保留轻微透视。
- 星链定位星由 12px 增大为 24px，数字放在菱形下方；当前值移到链名下方，避免与右端刻度挤在一起。
- 攻击次数按实际触发目标数编排；单次高伤害用重炮，多目标用连续弹道。修复按回血点数分段。动画消费已结算值，不再次计算伤害。
- Howler 限制同时发声数，左右声像对应双方，支持音量与停声。首次用户交互后才启用音频。

## 模型与资产

已匹配用户提供的 17 艘模型（玩家 1 艘、机器人 16 艘）。等级与原图关系见 `资产库/3D模型接入.json`；目前不需要补充模型。另一份我方模型作为重复设计没有另占等级。

`dist/assets/fleet-models.json` 保存每个模型的来源文件名、来源 SHA256、运行文件 SHA256、字节数、版本和实际分件数。GLB 内嵌纹理，无外链贴图。按当前等级加载，不在开局下载全部约 100 MB 的舰队。

Blender 预处理保留完整舰体，焊接重合顶点后切为六个带内部封口的分件。生命归零时隐藏完整舰体、展开分件并下坠；这属于预制断裂，不是实时物理破坏模拟。底层材质保留生成模型的纹理，近看质量仍受原始生成贴图限制。

可重建命令（先保留来源文件，脚本验证来源 SHA）：

```powershell
& 'D:\app\blender\blender.exe' -b --python scripts/prepare-detailed-fleet.py -- 'C:\Users\xutao\Desktop\飞船图'
```

性能边界：DPR 上限 1.65；即时粒子有数量上限；不活动模型释放 GPU 资源。二级模型原始分件材质较多，后续可单独烘焙图集；本次不损失纹理去强行合并。

## 验证与发布

`npm run verify` 包含 TypeScript、规则/回放/API/架构与资产检查以及 Vite/Worker 构建。测试中包含 80 局跨十六等级模拟、36 局镜像对称模拟和 48 局复盘证据检查；这些不代表真人胜率。

浏览器回归包含：完整人机对局并逐步对照预览与扣血/回血；补牌、帮助、记录和重开；五种屏幕尺寸（1920×1080、1774×887、1280×720、2560×1080、390×844）；WebGPU、强制 WebGL 2 与模型加载失败降级；十六级模型加载、我方近看/侧光和断裂场景。

CI 不使用生产凭据。预览部署使用独立 D1，并显式删除生产域名路由。正式上线沿用现有 Worker、Access 与 D1，不改迁移、不转移用户记录。此轮 GitHub 的自动发布变量未启用，未来获得试玩后的发布同意，再用已登录的官方 Wrangler 发布。本轮当前仅本地试玩，尚未创建 PR、推送或部署。

局限：自动浏览器测试不能代替长期游玩、所有 GPU/浏览器兼容矩阵或用户主观音效验收。未实现真人联网房间；未做实时物理碎裂；保留的 JS 规则和兼容模板可继续渐进迁移。
