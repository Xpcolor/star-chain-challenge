# V1.1.4 本地显示与终局反馈修复

仅本地候选，未提交、推送、PR 或部署。用户确认试玩后再发布。

## 根因与修改

- 复现生命值 `11 → 5` 后画面稳定显示 `0`，后续回血为 `6` 时甚至显示空白。规则与可访问标签仍为真实值。新建的一位数滚轮初始位置恰好是自身高度的 50%，GSAP 自动解析出了额外的 `yPercent: -50`，与 `em` 位移叠加。明确将百分比位移归零，并在位数减少时按个位对齐前值。修复双方生命和共用计数器；没有把错误画面当成真实零血，也没有修改胜负规则。
- 攻击项按伤害升序展示，同伤害保持原顺序；例如四项 `1、2、3、1` 显示为 `1、1、2、3`。React 与经典入口一致，只排序展示副本，目标 ID、伤害、规则顺序和回放均不变。
- 完整试玩另发现跃迁落点按钮会被补牌区遮住。桌面跃迁/定轨操作区改为按实际内容高度向上展开，底部保持原有间距，避免被固定底板覆盖。
- 游戏标题、玩法说明和构建版本同步为 V1.1.4。前一轮四分之一速度闪电、选定背景曲及两秒陨落展示保留。

- 攻击排序旧版 `1、2、3、1` 失败，新版顺序和编号通过。
