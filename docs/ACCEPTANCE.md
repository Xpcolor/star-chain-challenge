# 上线验收清单

这是待执行的线上验收要求。本地检查另见 VALIDATION.md；没有线上证据不得提前勾选。

| 项目 | 合格证据 |
| --- | --- |
| 仓库完整 | GitHub 含源码、图片、锁文件、迁移、测试与中文说明；clone 后可构建 |
| 公开但不允许陌生人写入 | 访客可读，协作者和应用权限已核对，匿名无写权限 |
| 主分支保护 | 远端已配置禁强推/删除、CI要求，维护者可正常通过 PR 合并 |
| 正式网址 | HTTPS 可玩，版本与正式提交一致，无缺失资源 |
| 游戏闭环 | 模块、骰子、出牌、结算、补牌、胜负、重开正常 |
| 规则回归 | 6手牌、16级、共享维修、立即致命、原模块次数及星域保持 |
| 记录同步 | 完成一局云端保存，刷新/重登录可查，统计一次 |
| 身份隔离 | 两测试用户互不可读，伪造旧平台身份头无效 |
| 离线/换账号 | 离线恢复、错误提示；切账号不串传队列 |
| 导出 | 局数、胜负、等级、支援与数据库对应，完整性可判断 |
| 历史迁移 | 备份、校验重放、重复导入幂等，不重复统计、不补造记录 |
| PR预览 | 至少一项真实 PR 提供最新提交对应的可玩网址 |
| 数据隔离 | PR绑定ID与正式不同，测试记录不会出现在正式库 |
| 外部PR安全 | 无密钥 CI；未审查代码不获得生产或部署凭据 |
| 发布闭环 | 合并测试 PR 后正式版本更新，固定网址不变 |
| 恢复 | 代码恢复可验证，旧记录仍可读；数据库备份单独处理 |
| 常用设备 | 桌面/手机常见尺寸核心操作可完成 |

只保存不含凭据和私人记录的日志与必要截图。证据不足写“待验收”和原因，不能以本地结果替代远端验证。
