# 星链算式：16级、可选支援与具体复盘

本次先在独立副本进行多轮模拟和回归，通过后才更新正式站点。6张手牌、星云3张、加速3张、折跃2张、双方18点生命和公开手牌延续。等级由9扩为16，最高机器人保留原有决策强度上限。

## 为什么增加到16级

先试验15级，在旧档位差距大的地方插入过渡策略。两组独立场景仍显示其中一处约12.7个百分点的落差，因此再补一个中间策略。避免仅以一个小样本的排序增减等级；最高档仍使用有限候选和有限预判，没有引入更深搜索。

随后对同水平机器人的先后手进行对照，固定3点护盾在低级对局补偿过多。比较0、1、2、3点方案，并用额外随机场景复核后，采用按实际等级固定的后手补偿：1–6级1点、7–12级2点、13–16级3点。开局显示本局数值。无论谁成为后手，都获得同一份补偿。

最终配置共13,824局：3组不同随机种子，每组72个场景，交换先后手，对照两种参考策略与全部16级。每个参考策略/等级有432局。每组覆盖全部36种模块配对及6种星域，各配对只覆盖分配给它的星域，并非216种组合的全因子测试。完整原始记录、每级区间和每个相邻差值的区间都保存在JSON与压缩流水中。

基础参考最大相邻下降为10.19个百分点，较强参考为9.95个百分点。基础参考最大反向波动为0.58个百分点，较强参考为1.85个百分点；单组样本也可能有更大波动。该结果支持比原九档更细的梯度，不等于每个玩家都感到严格等差。95%区间按同一场景的两次先后手配对聚类估计，使用正态近似，不是多重比较后的严格区间。

降低后手补偿后，重新运行全部受影响的1–12级、三个参考场景库；13–16级的规则、参数和3点护盾完全相同，因此保留对应结果。最终数据不包含15级试验局，也不把重复运行计算为新样本。

## 先后手与结算验证

另外两组场景完成4,608局同等级镜像对战，覆盖全部16级。先手总体得分率为48.22%。逐级结果及区间见 `balance/sixteen-mirror-summary.json`，原始流水另存。该检验与逐状态交换玩家、手牌、模块及进度的对称性回归相互补充。

梯度模拟核对了231,582次出牌预览与真实结算、27,648份局后统计，以及每局的牌张守恒、生命收支和12轮上限。原始参考策略与机器人都只能获取公开观察，后续抽牌顺序不可见。

## 支援与复盘

- 每个所选对手单独计数。两连败先提出邀请，接受才让下一局降低一级；拒绝保持当前难度，关闭只暂缓选择。又两连败才再次邀请。可反复接受，最低降到1级。两连胜恢复一级，最多恢复到所选等级；平局清空连胜连败，退出不计。
- 支援局沿用所选对手的身份与动画，名字加“（支援模式）”，明确显示实际等级。胜利按实际等级解锁。
- 接受和拒绝都进入详细记录。同一邀请只生效一次；离线队列按对局和选择的时间重传。旧版自动降级不会直接迁入本版，旧版记录、总局数与解锁按身份保留；旧对局重放仍使用原3点护盾。
- 局后给一条具体建议。有合适例子时，重建当时的公开牌桌，展示另一种合法出牌能造成的伤害/回血；确实能立即结束对局才指出收尾机会。其他情况结合实际维修争夺、模块使用或补牌给建议。即时收益不被解释成整局必胜。
- 16位对手有不同名字和颜色/飞行动作组合。使用原来的6种飞船图，不宣称新增16套独立模型。攻击和胜负动画继续使用原有流程，支持减少动画设置。

也可直接把 `docs/balance/sixteen-release-games.jsonl.gz` 传给汇总脚本，独立重算全部得分率和配对区间。该脚本遇到重复对局或未配对场景会报错。源码指纹见最终汇总文件。中间试验和旧版本报告作为历史资料保留。

功能回归使用实际引擎、DOM/时钟交互环境和内存SQLite，覆盖支援累加、接受/拒绝、重复点击、离线重载、并发写入、用户隔离、旧版真实记录重放，以及复盘中的合法收尾。浏览器画面和动画观感仍需真人设备试玩确认，自动化未替代真实浏览器视觉检查。模拟无法保证没有所有边界缺陷，也不等于真实留存验证；详细记录接口用于后续基于真实反馈继续调优。
