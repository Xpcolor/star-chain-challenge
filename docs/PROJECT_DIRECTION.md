## 当前版本：完整人机驾驶舱 1.1

正式入口为 Vite + TypeScript + React 界面，接入原有人机规则、机器人、回放和记录接口。统一 Three.js WebGPU 战场使用 TSL 材质和 RenderPipeline，支持 WebGL 2 后端与模型失败后的舰图降级。独立视觉样板 `/visual-sample.html` 与旧界面 `/classic.html` 只作对照。

用户已明确本次交付完整人机版，准备可替换的联网接口；真人房间后续实施。玩家固定使用当前这一艘飞船，不换船、不随等级换外形。近距离观察、真实转向和独立侧面受光仅提供给自己的飞船。机器人保留等级外观、飞入和战斗动效。

## 视觉与资产

- 宽屏透明驾驶舱；上方无遮挡，保留下部舷窗；侧板约 17% 底色和轻透视，底板约 20%。每侧仅两条长电弧沿统一外框与内部弓字形路线追逐，连接线走边缘空隙，内部不另开独立闪电。
- 功能牌统一中文名与配色：W 星云青蓝、A 加速橙金、J 跃迁紫色、D 定轨绿色、B 调拨金褐色；普通数字牌米白。星云数字选择器在橙星链下方，不覆盖刻度。
- 手牌、补牌与对方手牌统一尺寸；分类字与规则字等大；三项或四项维修按等级等高分布。星链定位菱形从 12px 改为 24px，数字位于其下方。
- 选中星链整条呈同色波动闪电，名称、定位星和“已选”状态同时增强。电弧共用 HUD 时钟并避开全部刻度数字；减弱动效时常亮，休整、非操作回合和重新开局不保留选中效果。验证见 `docs/qa/rail-lightning-verification.json`。
- 中途三选一统一约 97% 不透明深色底板；星域说明放在蓝星链上方，对战区上移。轮数字号与生命值一致；双方模块、校准按钮和说明、加减操作及等待提示增大。校准说明加宽，星云选数仍位于刻度下方。五视口、真实后段选择及完整对局验证见 `docs/qa/readability-verification.json`。
- 已接入玩家 1 艘、机器人 16 艘独立纹理 GLB。当前模型齐全，无须继续生成。来源与 SHA 见 `dist/assets/fleet-models.json` 和 `资产库/3D模型接入.json`。

## 架构与边界

`MatchClient` 统一指令、版本、对局 ID、回执和快照订阅；本地适配器驱动当前规则。React 管理操作与文字，Three.js 管理主战场，GSAP 与 HUD 共用场景时钟；Zustand 管理表现偏好。

经过验证的 `dist/engine.mjs` / `records.mjs` 继续使用 JavaScript。部分旧选择/说明模板通过兼容边界转为 React 节点，未宣称所有历史代码已改成 TypeScript。未来服务端还需要实现身份、权威房间、超时、断线恢复和数据一致性；本次不提供真人联机。
