# 九档难度发布复测

本版保留9级，通过逐步增加注意到的走法、缓慢降低随机性及逐级加强公开信息预判来平滑难度。预判的候选数不小于已注意的走法数量，避免启用预判时突然额外筛掉较差选择。最高档只做有限预判，不读隐藏牌库，也不做多回合深搜。

试行牌库：6手牌，普通数字36张，W3、A3、J2；18生命、后手3点一次性护盾、12轮上限均保留。

在若干校准样本后冻结参数，以新种子库8104573完成 **5,184局**独立模拟：每个参考策略×每个等级288局，涵盖144种场景并交换先手。模块36种组合均衡出现，六种星域均衡出现。参考策略从8或24个不同走法中选即时收益较高的走法，不等同于初学者/高手真人。

| 等级 | 参考策略8 得分率 | 参考策略24 得分率 |
|---|---:|---:|
| 1 | 92.9% | 100.0% |
| 2 | 75.3% | 99.0% |
| 3 | 64.2% | 99.0% |
| 4 | 47.6% | 94.6% |
| 5 | 37.3% | 90.6% |
| 6 | 24.8% | 79.2% |
| 7 | 18.6% | 74.7% |
| 8 | 10.1% | 62.1% |
| 9 | 4.9% | 53.5% |

得分率 =（胜局 + 0.5×平局）/ 局数。不是对真人胜率的保证。本次两条曲线的点估计均没有随等级升高而变容易，强参考策略在2、3级存在相同的99%天花板；无法由此断言每两个等级都能被真人感知。

较弱参考策略相邻最大下降17.5个百分点，较强策略最大下降12.5个百分点。相比前一轮九档试验出现的约26个百分点跳跃有所缓解，但使用了新样本，不能把两次差值当成严格的配对因果效果。配对区间保存在JSON报告中；仍需按玩家真实记录继续校准，不声称完全均匀。

最高级对强参考策略的记录为154胜、134负，参考策略胜率53.5%；说明当前上限可被有限策略战胜，不表示任意玩家都能达到该胜率。先手总体得分率47.54%，后手52.46%；平均8.69轮。没有根据局中输赢临时修改AI或发牌。

校验87,894次出牌预览与真实结算（其中3,344次折跃），10,368份双方局后复盘；无牌张丢失、生命账目偏差或超过12轮。另有43项自动回归，覆盖公开手牌、模块、共同任务、骰子、六手牌、折跃、旧解锁迁移、支援连降到1级、两胜恢复、跨用户隔离、版本冲突、记录重放、重复/乱序提交和断网重传。界面测试是DOM/时钟模拟，不是实浏览器视觉验收。

复现：

```sh
npm ci
npm test
node tests/ladder.mjs ladder 144 8104573 output.jsonl
```

`nine-release-summary.json`保留参数、源码SHA256和按场景成组重采样的区间；`nine-release-games.jsonl.gz`保留每一局的条件和结果。完整行动账目可由固定种子重跑。后续若更改引擎、模块、牌库或参数，应新建规则/参数版本再复测，不能沿用本次结论。
